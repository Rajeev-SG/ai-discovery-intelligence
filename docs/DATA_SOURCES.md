# Free data source strategy

v1 uses only freely accessible data/evidence. A company may sell a paid platform while also publishing useful free research; the public research is allowed, the paid dataset/API is not required.

## Source classes

### A — official product/search sources

Official docs, release notes, changelogs, crawler/user-agent documentation, search/web-grounding documentation, product blogs and press releases from OpenAI, Google, Microsoft/Bing, Anthropic, Perplexity, xAI, Meta, DeepSeek, Mistral, Alibaba/Qwen/Quark, ByteDance/Doubao, Tencent/Yuanbao, Moonshot/Kimi, Baidu, NAVER, Yandex and others in the surface registry.

### B — free market/traffic/behaviour telemetry

- Similarweb AI Search and company blogs
- Statcounter AI Chatbot Market Share pages / downloadable chart data where available
- DataReportal digital reports
- QuestMobile public research reports for China
- Adobe Digital Insights
- Cloudflare Radar / Cloudflare AI bot research

### C — free large-sample AI visibility research

- Peec AI blog/research
- Profound research hub/blog
- Ahrefs blog / free monthly studies
- Semrush blog/research
- SISTRIX blog/research
- Scrunch research/blog
- Evertune blog/research
- Seer Interactive research

These are commercially interested vendors. Store their methodology and vendor identity; do not treat claims as neutral ground truth.

### D — specialist editorial/discovery sources

Search Engine Land, Search Engine Roundtable, Search Engine Journal and reputable technology/business press. Use these for discovery and corroboration, not as a substitute for primary evidence when primary evidence exists.

### E — open research/discovery infrastructure

- GDELT DOC API for broad news discovery
- Google News RSS query feeds
- arXiv feeds/API
- OpenAlex API
- Crossref metadata API
- Common Crawl indexes where historical crawl evidence is useful
- RSSHub for feedless public sites
- SearXNG only as supplemental discovery, never canonical evidence

## Source discovery queries

Maintain monitored queries around:

- `<surface> search retrieval citations sources index crawler`
- `<surface> shopping recommendations ads`
- `<surface> referral traffic conversion`
- `<surface> query fanout web search`
- `AI search citations study`
- `AI referral traffic study`
- `generative AI consumer usage market share`
- `AI crawler user agent robots`

## Free-source rule

A source is not excluded merely because the publisher has a paid product. The decisive question is whether the exact evidence used by v1 is publicly accessible without a subscription/API contract.
